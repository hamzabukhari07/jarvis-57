# 🏢 Scranton Pixel Office & Multi-Agent Fleet Deck (ZEZO OS)

Autonomous pixel-art simulation and tactical command deck built for ZEZO Desktop OS.

## 🚀 How to Run
Open index.html directly in any web browser.

## 🌟 Key Features
- **12 Autonomous Scranton Agents:** Michael, Dwight, Jim, Pam, Oscar, Angela, Stanley, Kevin, Phyllis, Ryan, Toby, Creed.
- **Dynamic State Machine:** Seated typing, glowing monitors, walking (A* pathfinding), coffee breaks, boardroom sprint meetings, pair programming banter.
- **On-Demand Agent Inspector Drawer:** Right-side panel opens smoothly only when an agent is selected, showing:
  - Agent role, git worktree, and sandbox path.
  - Active in-progress files per agent.
  - Dedicated agent activity and telemetry log stream.
- **🚨 ALL HANDS Meeting:** Top bar trigger that summons all 12 agents to the boardroom simultaneously.
- **🖱️ Right-Click Tactical Context Menu:** Direct assignment, coffee breaks, pair programming, and circuit breaker halting.
- **🏢 Interactive Office Props:** Clickable Whiteboard (sprint goals), ZEZO Server Rack (CPU/vector DB stats), and Kitchenette (token usage).
- **🔊 Web Audio Retro Micro-Foley Synthesizer:** Pure Web Audio API synthesized mechanical keyboard clicks, water pour FX, and sirens with ON/OFF toggle.
