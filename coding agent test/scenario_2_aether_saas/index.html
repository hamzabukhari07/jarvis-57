Common Questions

Everything you need to know about Aether Metrics.

What is the performance overhead?
Aether Metrics is built on a highly optimized asynchronous core. Overhead is typically under 1ms, ensuring no perceptible impact on runtime performance.
How does AI pattern analysis work?
Our AI continuously learns your application's baseline behavior. When metrics deviate significantly, like unexpected latency spikes or unusual error clusters, it flags them proactively.
Can I export my telemetry data?
Yes, data can be exported via our REST API or pushed to custom webhooks on Pro plans.
