  ### Numbered End-to-End Step-by-Step Flow Map                                                                                                                                                                    
                                                                                                                                                                                                                   
  1. **fleet_control.py:346** — fleet_control() receives parameters={"action": "dispatch", "task": "build a portfolio", "agent_id": "VERVE"}.

  3. **fleet_control.py:64-66** — Checks is_web_agent (agent_id in ("VERVE", "FLUX")) and is_web_task (keyword match on "build portfolio").                                                                        
  4. **fleet_control.py:71** → **antigravity_agent.py:663** — Calls check_greenfield_gate(). If unconfirmed or missing info, returns prompt asking user for candidate info and confirmation.                       
  5. **fleet_control.py:79-94** — Enriches prompt with confirmed architectural parameters ([Stack: ..., Scope: portfolio, ...]).                                                                                   
  6. **fleet_control.py:96-112** — 12-second debouncing check prevents duplicate dispatches to the same agent.                                                                                                     
  7. **fleet_control.py:113** → **fleet_manager.py:688** — Calls fleet_manager.dispatch_task().                                                                                                                    
  8. **fleet_manager.py:288-294** — resolve_agent_by_mention_or_capability() matches keyword "portfolio" to VERVE.

  12. **fleet_manager.py:754-768** — Queries skill_loader for agent.allowed_skills (website_build) and extracts procedural rules.                                                                                  
  13. **fleet_manager.py:770** — Enriches prompt with agent persona, prompt prefix, and active skill instructions.

  18. **fleet_manager.py:777** — Background thread executes _worker_fn().                                                                                                                                          
  19. **fleet_manager.py:781-807** — Wraps task_ctx.report with _reporting_wrapper to sync desk logs and emit "task_progress" events.

  23. **antigravity_agent.py:310-311** — Calls _ensure_gitignore(repo) and capture_repo_snapshot(repo) for undo baseline.                                                                                          
  24. **antigravity_agent.py:313** → **design_resolver.py:184** — Calls is_ui_task(task) → returns True.                                                                                                           
  25. **antigravity_agent.py:316** → **design_resolver.py:590** — Calls resolve_design(task, repo_path=repo).                                                                                                      
  26. **design_resolver.py:608** — extract_authentic_task() strips agent headers and skill blocks to prevent matching pollution.                                                                                   
  27. **design_resolver.py:461** — _infer_scope() classifies request as "portfolio".                                                                                                                               
  28. **design_resolver.py:491** — resolve_from_catalog() queries catalog.json, matches Hairline Grid Engineer Portfolio.html, and returns ResolvedDesign.                                                         
  29. **antigravity_agent.py:336-352** — Copies resolved HTML template directly to {repo}/reference.html and reports milestone at 8%.                                                                              
  30. **antigravity_agent.py:360-380** — Injects build specifications and the 2-sentence read-only reference directive into CLI prompt.                                                                            
  31. **antigravity_agent.py:382** — Captures pre-execution directory snapshot via _tree_snapshot(repo).                                                                                                           
  32. **antigravity_agent.py:384-403** — Spawns agy CLI via subprocess.Popen with CREATE_NO_WINDOW.                                                                                                                
  33. **antigravity_agent.py:407-417** — Limits CPU affinity to half logical cores via Windows Job Object.                                                                                                         
  34. **antigravity_agent.py:421-433** — Spawns _reader background daemon thread to stream CLI output.                                                                                                             
  35. **antigravity_agent.py:436-462** — Polling loop checks new files generated and reports progress (20% – 90%).                                                                                                 
  36. **antigravity_agent.py:487-501** — Captures after snapshot via _tree_snapshot(); verifies new deliverable files exist.                                                                                       
  37. **antigravity_agent.py:504-511** — Calls register_repo_undo(repo, snapshot) and updates session memory.                                                                                                      
  38. **antigravity_agent.py:513-515** — Calls _launch_smart_preview(repo) to open the built portfolio in the default browser.                                                                                     
  39. **fleet_manager.py:923-931** — Reports 100% progress, invokes complete_task(), and emits "task_done" and "fleet_updated" events.
