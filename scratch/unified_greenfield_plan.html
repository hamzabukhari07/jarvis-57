Phase 1: Intake Gate & 5-Pillar State Machine

Target Files: actions/antigravity_agent.py, actions/fleet_control.py, core/prompt.txt

  • Implement unified 5-pillar extraction (`scope_type`, `entity_content`, `tech_stack`, `color_theme`, `key_sections`).
  • Enforce 2-step confirmation gate: prompt for missing pillars in Step 1, read back plan and require `confirmed=true` in Step 2.
  • Portfolio Scope Handling: If `scope_type == 'portfolio'` and no `entity_content`/resume present, return a prompt asking for name, role, key projects, or a desktop resume PDF.
def check_greenfield_gate(task: str, parameters: Dict[str, Any]) -> Optional[str]:
    scope = parameters.get("scope_type", "general")
    if scope == "portfolio" and not parameters.get("entity_content"):
        return "Portfolio build requires candidate entity content or resume PDF. Please provide name, role, key projects, or attach resume PDF."
    if not parameters.get("confirmed", False):
        return "BUILD NOT STARTED. Read the 1-sentence plan back to the user and ask for confirmation."
    return None
