## 🚀 Quick Start (Local Development)

```bash
cd zezo-waitlist
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🛠️ Features Included

- **Anti-Slop Aesthetics:** Obsidian dark mode, subtle grid texture, zero cliché purple gradients, refined 1px border hierarchy.
- **Micro-Interactions:** Smooth inline state transition from email input to green checkmark badge upon submission.
- **Real-Time Queue Counter:** Live simulated waitlist counter with local browser persistence.
- **Zero Cost Backend:** Free Google Sheets storage via Google Apps Script (see `GOOGLE_SHEETS_SETUP.md`).
- **Production Optimized:** Built with Vite 6 + Tailwind CSS v4 + TypeScript. 1-second build time.
