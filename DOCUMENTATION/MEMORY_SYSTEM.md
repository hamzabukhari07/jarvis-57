# JARVIS — Memory System

## Storage
memory/long_term.json. Categories: identity, preferences, projects, relationships, wishes, notes, sessions, monitors. Max 200k chars.

## Prompt Budgeting
Identity always in full. Recent entries (900 chars). Index (420 chars) for recall_memory.

## recall_memory
Local file search (instant). Lexical scoring. Up to 8 results.

## Session Memory
Conversation summaries at shutdown. Up to 3 recent sessions. Morning briefing references last session.
