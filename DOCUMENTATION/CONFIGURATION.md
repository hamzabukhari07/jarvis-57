# JARVIS — Configuration

## Configuration Files
config/api_keys.json: API key, name, voice, toggles, plugin settings, audio devices.

## Configuration Management
All settings via memory/config_manager.py.

## Voice & Language
get_voice()/save_voice(). Available: Charon, Puck, Kore, Fenrir, Aoede.

## Features
Wake word toggle, push-to-talk, proactive audio, thinking enabled, media resolution, turn tuning.

## Audio Devices
get_input_device()/save_input_device(). Name-based storage.
